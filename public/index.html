CONNEXION LOCALE

Le moteur, en coulisses.

Ce studio utilise l’API de ton installation ACE-Step. Le modèle reste chargé dans un seul moteur.

Sur ton Mac, arrête d’abord Gradio avec Ctrl+C, puis lance l’API dans son dossier :

cd "$HOME/Applications/IA/ACE-Step-1.5"
bash start_api_server_macos.sh

Adresse attendue : http://127.0.0.1:8001

Le premier chargement peut prendre quelques minutes. Le studio conservera les morceaux qu’il crée dans son dossier .data.
